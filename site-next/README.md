# Лендинг ЛОРдока

React + Vite + Tailwind 4. Направление B: врачебная документальность.

## Разработка

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build     # результат в dist/
```

Собранная папка отдаётся тем же nginx, что и сейчас. Каталог
`/opt/lordok_bot/site` на сервере общий для нескольких сайтов, поэтому
выкладывать нужно только содержимое `dist`, не трогая `nginx.conf` и
чужие каталоги. Страницы `privacy.html` и `terms.html` остаются на
месте, ссылки в подвале ведут на них.

## Дизайн-токены

Все цвета и шрифты в `src/index.css`, блок `@theme`. Контраст каждой
пары посчитан и записан в комментариях рядом со значением. Тёмная тема
описана отдельным набором значений, а не инверсией, и переключается
и системной настройкой, и атрибутом `data-theme`.

Заголовки набраны PT Serif: из отобранных серифов только у него
кириллица родная. Newsreader, который советовала база подбора, кириллицы
не имеет вовсе и молча падал бы в системный шрифт.

## Содержание

Тексты и цифры лежат в `src/data.ts`. Каждое число там либо из нашего
кастдева (18 интервью, Q4 2025 — Q1 2026), либо из клинических
рекомендаций. Цифры без источника на страницу не выносим.

## Движение

Уровень Subtle из motion-базы ui-ux-pro-max: 350 мс, кривая power1.out,
сдвиг 12 px. Единственное исключение — выписка в первом экране: она один
раз проигрывает неделю, чтобы за полторы секунды показать, как дневник
доходит до рекомендации.

Правила, которые нельзя нарушать при правках:

- заголовок, подзаголовок и кнопки первого экрана не анимируются;
- три состояния триажа, цифры кастдева, дисклеймер и юридические
  ссылки появляются сразу и всегда;
- прятать блоки умеет только класс `js-motion` на `<html>`, который
  ставится скриптом в `index.html` и только когда система не просит
  убрать анимацию. Нет скрипта или включён prefers-reduced-motion:
  страница статична и полна;
- если наблюдатель за видимостью почему-то не сработал, блок всё равно
  показывается через 3 секунды (`REVEAL_FAILSAFE` в `src/motion.ts`);
- анимируются только `transform` и `opacity`.

GSAP намеренно не подключён: на этом уровне интенсивности хватает
CSS-переходов и одного IntersectionObserver, а библиотека добавила бы
около 35 КБ в gzip. Сниппеты из базы использованы как спецификация
длительностей и кривых.
